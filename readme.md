# Mục 1: Thông tin sinh viên
- Họ và tên: [Lương Hải Nam]
- Mã sinh viên: [24810310448]
- Tên đề tài: [Chọn bài được giao: 5.3 Cafe POS / 5.4 Hotel / 5.5 Inventory]

## Mục 2: Hướng dẫn cài đặt
1. Cài SQL Server và SQL Server Management Studio (SSMS).
2. Mở SSMS, chạy **một** script phù hợp trong thư mục `Database/`:
   - `CafePOSDB.sql` cho bài 5.3.
   - `HotelDB.sql` cho bài 5.4.
   - `InventoryDB.sql` cho bài 5.5.
3. Mở dự án C# bằng Visual Studio 2022. Với CafePOSSystem, tạo project **Windows Forms App (.NET Framework)**, thêm các file `.cs` theo cấu trúc thư mục, đặt `App.config` ở project root và tham chiếu `System.Configuration`.
4. Sửa `Data Source=.` trong `App.config` cho đúng instance SQL Server của máy bạn (ví dụ `.\SQLEXPRESS`).
5. Build và chạy bằng F5.
